# PS Scientific Calculator 🧮

A modern **scientific calculator** built using **HTML, CSS, and JavaScript**.  
This project supports basic arithmetic operations along with additional scientific functions.

---

## 📌 Features

### ✅ Basic Operations
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)

### 🧠 Scientific Functions
- Square (x²)
- Square Root (√)
- Percentage (%)

### 🎨 UI Features
- Clean and modern design  
- Responsive layout  
- Easy-to-use interface  

---

## 🛠️ Technologies Used

- **HTML** – Structure  
- **CSS** – Styling & layout  
- **JavaScript** – Logic and calculations

## ▶️ How to Run the Project

### Method 1: Direct Run
1. Download or clone the repository  
2. Open the project folder  
3. Double-click `index.html`

### Method 2: Using VS Code (Recommended)
1. Open the folder in VS Code  
2. Install **Live Server** extension  
3. Right-click `index.html` → **Open with Live Server**
